
# Analiza meczu

Ten projekt służy do analizy danych z meczów piłkarskich.  
Planuję używać Pythona do przetwarzania danych, tworzenia wykresów i generowania statystyk.

## Planowane funkcje:
- Wczytywanie danych z plików CSV
- Obliczanie statystyk zawodników i drużyn
- Wizualizacja wyników (wykresy, tabele)
- Eksport raportów
